# 0.33443提出モデル：モデル構成と残差ポリシーの効果

## 1. 対象

本書の対象は、`parc2026_submission_0.33443.zip` に収録された提出モデルである。比較対象を次のように定義する。

- **ベースポリシー:** カメラ画像、ロボット状態、作業指示から基本となる行動を生成するSmolVLA
- **残差ポリシー:** ベースポリシーが生成した行動を、現在のロボット状態に応じて小さく補正する追加ネットワーク
- **最終出力:** ベースポリシーの行動に残差ポリシーの補正を加えた7次元行動。ただし、残差ポリシーが変更するのは手先の移動3成分と回転3成分のみで、グリッパー開閉はベースポリシーの出力をそのまま使う。

## 2. モデル構成

### 2.1 ベースポリシー

ベースポリシーは、画像と言語を扱うSmolVLM2と、ロボット行動を生成するネットワークを組み合わせたSmolVLAである。入力と処理の流れは次のとおりである。

1. 正面カメラ画像と手首カメラ画像を、画像認識部で特徴量へ変換する。
2. 英語の作業指示を単語列に分解し、言語特徴量へ変換する。
3. ロボットの現在状態8次元を、1層の全結合層で言語・画像特徴量と同じ空間へ写す。
4. 画像・言語側16層と行動生成側16層のTransformerで情報を統合する。Transformerは、入力のどの部分を重視するかを段階的に計算するネットワークである。
5. 行動入力用の1層、時刻情報を処理する2層、行動出力用の1層の全結合層を介して、50時点分の行動を生成する。

画像・言語モデル自体の設定ファイルには言語部32層と記載されているが、SmolVLAとしての推論ではその先頭16層を使用する。特徴量の幅は画像部768、言語部960、行動生成部は言語部の0.75倍に相当する720である。画像は2視点とも256×256画素として入力され、作業指示は最大48トークン、すなわちモデルが扱う単語片48個までである。

ベースポリシーは一度に50時点分の行動列を予測する。実行中は5時点ごとに再予測し、新旧の予測が重なる部分を平均する。これにより、計算量を抑えつつ、直近の観測を反映し、行動の急変を減らしている。

### 2.2 残差ポリシー

残差ポリシーは、全結合層3層からなる小型MLPである。

- 入力: ロボット状態8次元＋ベースポリシーの行動7次元＝15次元
- 第1層: 15次元から128次元へ変換し、SiLU活性化関数を適用
- 第2層: 128次元から128次元へ変換し、SiLU活性化関数を適用
- 第3層: 128次元から6次元へ変換し、tanhで出力範囲を制限
- 出力: 手先の移動3成分と回転3成分に対する補正

パラメータ数は、各全結合層の重みとバイアスを合計して **19,334パラメータ** である。補正の絶対上限は移動方向ごとに0.02、回転方向ごとに0.03であり、0.33443提出版ではさらに0.25倍して適用する。したがって実際の最大補正量は、移動が各方向0.005、回転が各方向0.0075である。残差ポリシーは画像や言語を直接見ず、ベースポリシーの判断を置き換えない。現在状態に応じて行動を少しだけ修正する役割に限定している。

学習には591エピソード、39,978時点分の実行記録を用いた。各記録には、現在状態、ベースポリシーの提案行動、実際に実行した行動、報酬が含まれる。成績の良い軌跡を強く学習する重み付き模倣学習を行い、ベースポリシーは固定したまま残差ポリシーだけを5,000更新学習した。

## 3. 実験したタスク

残差ポリシー導入前後の直接比較では、次の5タスクを使用した。

| タスク | 環境変化 | 主に確認した点 |
|---|---|---|
| コンロ上の黒いボウルを皿へ移す | 机の外観変更 | 対象物への接近、把持、皿への移動 |
| テーブル中央の黒いボウルを皿へ移す | 照明変更 | 明るさが変わっても把持位置を保てるか |
| アルファベットスープ缶をかごへ入れる | 机の外観変更 | 小型物体の把持と投入 |
| キャビネット中央の引き出しを開ける | 照明変更 | 取っ手への接近、把持後の引き動作 |
| ボウルをコンロへ置く | 照明変更 | 周辺物体との衝突を避けて配置できるか |

最初の4タスクは、各1エピソード、最大200時点、同一seed 31415で簡易比較した。ベースポリシーは4件中3件成功、残差補正を0.25倍で加えたモデルは4件すべて成功した。変化が確認できたのは「キャビネット中央の引き出しを開ける」で、ベースポリシーは失敗、残差ポリシー導入後は139時点で成功した。他の3タスクは導入前後とも成功している。

「ボウルをコンロへ置く」は残差ポリシー導入後に20エピソードで追加確認し、成功率90%、衝突率10%だった。ただし、同じ20エピソード条件のベースポリシー結果が保存されていないため、この値だけから残差ポリシーによる改善量を算出することはできない。

4タスク比較は各1回のみであり、統計的な性能保証ではなく、改善例を見つけるための予備実験として扱う必要がある。

## 5. 改善された原因の考察

改善の第一の要因として、引き出し操作では小さな位置・姿勢誤差が成功と失敗を分けやすいことが挙げられる。取っ手へ近づくだけでは不十分で、適切な高さと向きで接触し、把持状態を保ったまま一定方向へ引く必要がある。ベースポリシーは作業全体の方針を生成できても、取っ手周辺で数値的にわずかな誤差を残す場合がある。残差ポリシーは現在のロボット状態とベース行動の組合せから、この局所的な誤差を補正した可能性が高い。

第二に、残差ポリシーを「新しい行動を一から生成するモデル」ではなく「小さな修正だけを行うモデル」に制限した点が有効だったと考えられる。提出版での最大補正は移動0.005、回転0.0075と小さい。これにより、ベースポリシーが既に正しく判断している接近方向や作業順序を壊さず、接触位置や引く方向だけを調整できる。実際、簡易比較では、ベースポリシーが成功していた3タスクは残差導入後も成功を維持した。

第三に、学習時にエピソードの成績に応じた重みを付けたことで、成功につながる修正が優先された可能性がある。保存された39,978時点に対するオフライン評価では、実行された行動との平均二乗誤差が0.01021から0.00987へ約3.3%減少している。これは実環境での成功率を直接保証する値ではないが、残差ポリシーがベース行動を実行データ側へ小さく近づけていることを示す
