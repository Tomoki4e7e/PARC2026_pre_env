# 学習・推論レポート（提出スコア 0.33443）

本書は `/home/cm-pc/PARC2026_submission/parc2026_submission_0.33443.zip` の内容を直接確認して作成した。モデルや学習に詳しくない読者にも分かるよう、提出物の動作と学習過程を中心に説明する。

## 1. モデルの概要と推論方法

提出モデルは、カメラ画像と言語指示からロボットの動きを決める **SmolVLA** を主モデルとし、その出力を小型の補正モデルで微調整する二段構成である。主モデルへの入力は正面カメラ画像、手首カメラ画像、ロボットの位置・姿勢等を表す8個の数値、および最大48単語相当の英語指示である。出力は、手先の移動3成分、回転3成分、グリッパー開閉の計7成分である。

モデル名・版は、提出物を識別できるよう **SmolVLA 環境変化対応・行動補正版 0.33443（2026-08-12）** とする。基になった公開モデルは Hugging Face Hub の `lerobot/smolvla_libero_plus` であり、その内部の画像・言語処理モデルは `HuggingFaceTB/SmolVLM2-500M-Video-Instruct` である。使用した公開モデルの revision（公開リポジトリ内の版を一意に示す識別子）は `7bb70aa5bc92b82c9239142775d3a173103567ff`、画像・言語処理モデルのローカル保存版は `7b375e1b73b11138ff12fe22c8f2822d8fe03467` である。

主モデルは1回の計算で将来50時点分の行動候補をまとめて出す。これを **Action chunk** と呼び、本モデルでは chunk長50である。ただし、50時点をそのまま固定して実行するのではなく、5時点ごとに新しい予測を作る。新旧の予測が重なる部分は、重み係数0.01の加重平均で滑らかにつなぐ。この方法により、毎時点大きなモデルを動かす計算量を抑えながら、古い予測への依存も減らした。主モデル内部では1回の予測を10回の反復計算で生成する。

その後、補正モデルが主モデルの行動と現在のロボット状態を受け取り、移動・回転の6成分だけをわずかに修正する。グリッパー値は変更しない。補正モデルは128ユニットの中間層を2層持つ全結合ニューラルネットで、補正量の上限は移動0.02、回転0.03、さらに提出時は全補正を0.25倍している。これにより、主モデルの能力を保ちながら局所的なずれだけを直す設計とした。

言語指示については、大文字・小文字や物体名の表記差により同じ作業を別物と誤認しないよう、評価時の指示を学習時の表現へ置き換える。未知の指示を無理に既知作業へ割り当てる方式は誤判定が増えるため採用せず、既知の対応表と規則的な言い換えだけを使用した。また、行動列の先頭だけを一律に弱める方法も試したが性能が下がったため無効にした。ボウルをコンロへ置く作業では、画像から障害物への接近を検出した場合に移動方向を小さく補正する安全処理も組み込んだ。別途用意した衝突予測モデルのプログラムは含まれるが、その重みは提出物にないため実際には使用されない。

## 2. 学習データ

主な学習データは、ロボット操作の模範動作を収録した公開データセット `lerobot/libero_plus` である。使用したデータ revision は `f3f49f426d75030177b18778374005bc12ccd588`。画像、ロボット状態、正解行動、英語の作業指示を含む。

最初に、黒いボウルを位置関係に従って運ぶ10作業について、各5エピソード、計50エピソードで3,000 step学習した。次に評価対象で弱かった4作業、すなわち「引き出し内の黒いボウルを皿へ置く」「牛乳をかごへ入れる」「トマトソースをかごへ入れる」「ボウルをコンロへ置く」へ重点化した。割当は順に50、40、50、30エピソードの計170エピソードで、10,000 step学習した。

最後に、評価環境で起こる机の見た目や照明の変化に強くするため、シミュレーター上で見た目を変えて独自生成した再実行データを追加した。公開データから選んだ通常動作41エピソードと、見た目を変えた環境で得た41エピソードを1対1で混合し、計82エピソード、10,669画像時点を使用した。この追加学習は3,000 stepである。

補正モデルには、実際に主モデルを動かして記録した591エピソード、39,978時点分のデータを用いた。各エピソードの成績が良いほど学習上の重要度を高くする方法で、凍結した主モデルの出力をどの方向へ直すべきか学習した。重み付けの温度は10.0、学習は5,000 step、乱数seedは42である。補正モデルの保存記録には学習率とbatch sizeが残っていないため、これらは未確認値として扱う。

## 3. 学習方法と主な設定

主モデルでは **LoRA** を使用した。LoRAは、公開モデル全体を更新する代わりに、小さな追加行列だけを学習する省メモリ型の追加学習方法である。したがって Full fine-tuning（全パラメータ更新）ではない。学習後は追加行列を主モデルへ統合したため、提出時には単一の重みファイルとして動作する。

最終の見た目変化対応学習では、画像認識部分を固定し、LoRAのrank 16、alpha 16、batch size 1、bf16、seed 42を使用した。学習率は `2e-5` から `2e-6` へ減衰させ、最初の100 stepをウォームアップ期間とした。正規化に用いる平均・標準偏差は直前のモデルから維持した。弱点4作業の学習では、LoRA rank 32、alpha 32、学習率 `1e-4` から `1e-5`、batch size 1、100 stepのウォームアップを使用し、画像認識部分を固定した。

補正モデルについては小型ネットワーク全体を学習した。これは主モデルのLoRAとは別の Full trainingである。ただし主モデル自体は固定されており、補正モデルのみを更新した。

試行錯誤では、通常環境だけでの追加学習、照明・机の見た目を変えたデータの混合、行動列の平均化、指示文の正規化、補正量の倍率変更を比較した。最終的に、見た目を変えたデータを50%混ぜること、5時点ごとの再予測、指示文の保守的な正規化、補正倍率0.25を組み合わせた。大きな補正や強制的な言語変換は個別作業を改善しても他の作業を悪化させる場合があり、全体性能と安定性を優先して抑制した。
