# タスクの大まかな構想
- LIBEROの関連タスクを利用して、靴下の着衣支援モデルの性能検証を行いたい
- 導入するモデルは/home/cm-pc/catkin_ws/src/inoueに記述されている
- 着衣支援モデルではBase PolicyにSAMDAMSARNNを用いているが、今回の検証では比較をわかりやすくするために、既存のSmolVLAをBase Policyとして利用する
- 着衣支援モデルとLIBEROで利用できる情報が異なるため、適宜修正した残差ポリシーを利用する
- 既存のSmolVLAのみの場合と、着衣支援モデルの残差ポリシーをLIBEROに合わせて修正したものをSmolVLAに上乗せしたモデルで比較し、成功率が上がるかどうか確かめる
- 実験の詳細についてはexperiment_plan_a.mdを参照する
