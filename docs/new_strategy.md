# 探索データの拡張
- より様々な色彩、コントラスト、テクスチャでの軌跡の成功データを集めて学習できないか
    - 変化させる対象: 照明、背景、非対象物、カメラ
    - 検証対象：公開4タスク、table/light 200タスク、hold-out (学習時間が現実的な範囲で探索を行う)
    - 色や明るさの範囲 : 照明が明るい、暗い、両方を想定
    - 1タスクあたりの派生環境数と初期状態数 (学習時間、メモリが現実的な範囲で増やす)
    - 失敗軌道もRL用に保存する

# 残差強化学習の実装
- 現在のACTによるBase Policyに残差ポリシーを上乗せする
    - 現行SmolVLAをBase Policyとする
    - 残差対象：並進、回転
    - 残差の最大値
        - 並進: ±0.02
        - 回転: ±0.03
    - Base Policyは完全に凍結する
    - 残差適用位置：Temporal Ensembleの後
    - 全タスク共通モデル
- 過去の起動データ全てから報酬が最大となる軌道を探索する
    - 今後の全ロールアウトをRL形式で保存する（obs/action/reward/next_obs/done/collisionをエピソード単位で保存する）
    - 上の探索データの拡張の結果次第
- 報酬計算はコンペの評価式に従うが、衝突した時に大きなペナルティを課すようにする
    - 正式な評価式はparc2026-preliminary-rules.mdc以上のことはわからない
    - 成功までの短さや滑らかさも報酬に含める
    - 1mmh判定を学習時も利用する
    - 学習用のdense rewardを許容する

# 優先順位

1. 今後のロールアウトを完全なRL遷移形式で保存する
2. 既存軌道を再生してreward/collisionを再ラベルする
3. 報酬重み付きBCで小規模な効果検証
4. 状態＋Base行動を入力する小型残差ポリシーを追加
5. データ量が十分ならIQL/CQLなどのOffline RLへ進む
6. 照明・背景textureの実レンダリング収集を並行実施
